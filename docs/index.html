Stats Project Part I: Markov Chain Weight Generator

This project creates a CSV file that represents the probabilities of the next word of a sequence in a Markov Chain.

Rough Plan

  1. First, go through the text and identify unique words.
  2. Create columns and rows of the matrix with each unique word.
  3. For a given word, go through the whole text and count the number of times each different word comes after it. Possibly in a vector of a class with a name and count as members.
  4. Do the division (to find probabilities) and add these numbers to the matrix. Having the words in the rows/columns and vector in the same order (alphabetical) might make writing the numbers easier.
  5. Do this for all words of the matrix.
